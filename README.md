# killer — 杀手数独

终端里的杀手数独 (Killer Sudoku): 生成谜题、回溯求解、自带自检。
纯 Python 标准库,无第三方依赖。

## 规则

9×9 标准数独规则之上,再加"笼子"约束:

- 每个笼子(虚线/字母标出的连通区域)内的数字**互不相同**;
- 笼内数字之和等于笼子左上角标注的**目标和**;
- 单格笼子相当于已知数。

## 用法

```bash
python -m killer                  # 生成一道谜题
python -m killer --seed 7         # 固定种子,可复现
python -m killer --seed 7 --solve # 生成并求解,打印答案与验证结果
python -m killer --max-cage 4     # 笼子最大 4 格(默认 5)
python -m killer --selftest       # 运行内置自检
```

示例 (`--seed 7 --solve`,节选):

```
杀手数独 (seed=7, 28 个笼子):

 E12  Y18  P12  P    U 6  F20  O21  J16  a 5
 ...

答案:

2 4 9 | 3 6 8 | 7 1 5
...

验证: 合法
```

## 实现要点

- **生成**: 先随机回溯生成完整数独解,再从该解出发随机"生长"笼子
  (只允许加入不与笼内重复的数字,从构造上保证笼内无重复),
  笼子和由该解反推——所以生成的谜题至少有一个解。
- **求解**: MRV(最小剩余值)回溯 + 笼子组合剪枝。
  每个笼子预计算"和为目标的互异数字组合",填数时只保留
  与已填数字相容的组合,剪枝效果明显。
- **验证**: 独立的 `check_solution` 检查行/列/宫、笼内无重复、
  笼和正确、笼子覆盖全部 81 格。

## 真实验证记录

- `python3 -m py_compile killer.py __main__.py` 通过
- `--selftest` 5/5 通过 (约 34 秒):
  - 手工谜题: 经典数独解 + 手工划分的 27 个 3 格笼
    (和数手工计算,抽查 5+3+4=12、8+5+3=16 一致),
    已知解通过独立验证器,求解器找回合法解;
  - 10 个种子生成的谜题全部可解,解全部通过独立验证
    (数独 + 笼和 + 笼内无重复),生成器"笼内无重复"不变式逐笼断言。

## 已知局限 (诚实版)

- 生成的谜题**不保证唯一解**,只保证可解;求解器返回找到的第一个解。
- 求解是大规模回溯,个别"运气不好"的谜题可能需要数秒;
  `--max-cage` 越大、单格笼子越少,通常越慢。
- 生成器不做难度分级,就是"能解"级别的小玩具。
- 无交互式填涂,只有"看题 + 对答案"模式。
- 需要 Python 3.10+。
